# FKU Website Prototype

A static, responsive prototype for **FKU — Fat Kids United**.

## Open it
Double-click `index.html` or serve the folder with any static web server.

Example with Python:
```bash
python -m http.server 8080
```
Then open `http://localhost:8080`.

## Files
- `index.html` — page content / structure
- `styles.css` — complete responsive visual system
- `script.js` — menu, simulated music player, signup demo, interactions
- `assets/` — FKU concept artwork from the current design exploration

## Intent
This prototype deliberately positions FKU as a **media / creator collective first** and merchandise second:
- FKU After Hours — main variety stream/show
- FKU Radio — Wayne's music and freestyles
- FKU Arcade — gaming/anime content
- FKU Test Kitchen — food content
- FKU Goods — limited merchandise tied to content

No backend, real email capture, checkout, or streaming integration is included yet.
